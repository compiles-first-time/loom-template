# ADR-0060: Claim provenance verification — resolve sources, cap confidence

**Status:** Accepted (architect directive 2026-08-13)
**Date:** 2026-08-13
**Author:** Builder session — approved by Nick
**Confidence:** [H] that self-reported provenance is unreliable; [H] on the three-state model; [M] on the specific numeric caps (calibrate against outcomes)

## Context

Since v0.2 the CLAUDE.md **claim convention** has required every non-trivial claim to carry
`confidence`, `sources`, `what_would_raise_to_95`, and `decision_log`. The mechanical half
of Rule 22 is enforced by hooks. The introspective half — including provenance — was left
to the model.

**Nothing ever checked a single source.** A hand-typed `sources: ["arXiv:1234.5678"]` was
byte-identical to a verified one. Rule 22's provenance requirement was, in practice,
satisfiable by typing.

The literature makes clear this is not a tolerable gap:

- Citation-hallucination rates of **11–57%** across commercially deployed models
  `[arXiv:2606.00898, arXiv:2605.27700][T1][V1]`
- Deep-research agents **cite sources they never verified** — the precise failure mode of
  an agent-populated `sources` array `[arXiv:2605.06635][T1][V1]`
- Automatic attribution checking is itself hard: AttributionBench tops out near **80%
  macro-F1**; on CiteME, LLMs pick the correct paper to cite **4–18%** of the time. So a
  *judge* cannot be the citation checker either — it needs retrieval plus deterministic
  identifier resolution.
- **The decisive finding:** Dahl, Magesh, Suzgun & Ho, *Large Legal Fictions*, **Journal of
  Legal Analysis** (>800,000 verifiable questions; hallucination **58%** GPT-4 to **88%**
  Llama 2) — models *"struggle to predict their own hallucinations."*
  `[arXiv:2401.01301 + peer-reviewed + public replication repo][T1][V1]`

That last clause forecloses the cheap fix. If a model cannot predict its own hallucination,
then asking it to self-report confidence in a source is asking for a number generated by the
same process that produced the error. Provenance must be resolved **by code**.

This session supplied its own live demonstration. Asked to verify the citations in a
research review, it found `arxiv.org`, `huggingface.co`, `metr.org`, and
`api.openalex.org` all blocked by the environment's egress proxy — meaning **no citation in
that review could be fetched and read.** A binary valid/invalid checker would have had to
call every one of them a failure, which is false: they are *unchecked*, not *wrong*. That
distinction became the core of this design rather than an afterthought.

## Decision

**1. A three-state resolution model.** `scripts/lib/claim-provenance.mjs` resolves each
source to exactly one of:

| Status | Meaning | Is it a defect? |
|---|---|---|
| `resolved` | the referent provably exists (file found, or HTTP 2xx/3xx) | no |
| `unreachable` | could not check — offline mode, proxy 403, 429, 5xx, DNS failure, timeout, or an opaque label naming nothing checkable | **no** — an environment fact |
| `unresolvable` | checked, and it is not there — missing file, HTTP 404/410, Rejected-tier host, malformed identifier, **or the quoted span is absent from the referent** | **yes** |

Conflating `unreachable` with `unresolvable` is explicitly forbidden. Punishing an operator
for a blocked proxy teaches them to stop citing, which is strictly worse than the problem.

**2. Six resolvable source forms**, four of which need no network: repo path (with optional
`#anchor` / `:line`), `ADR-NNNN`, `LR-NN`, `BR_NN`, plus `arXiv:id` / `doi:` / URL. In-repo
referents are **Tier 1** — the artefact *is* the primary source — and are the cheapest,
strongest provenance Loom can have.

**3. The quoted-span check is the real teeth.** Supplying the sentence being relied on
promotes a source from `V1` (exists) to `V2` (says what the claim says), recording a
`sha256` of the normalised span. **A referent that exists but lacks the span resolves to
`unresolvable`, with the detail "the citation misrepresents the source."** A URL returning
200 is not evidence that the claim is in it — that gap is where "cited but not verified"
lives.

**4. Verification is a level, not a boolean.** New `V0`–`V4` ladder, orthogonal to
ADR-0009's source tiers:

| Level | Meaning |
|---|---|
| `V0` | asserted; nothing resolved |
| `V1` | exists / search-attested — not read |
| `V2` | fetched and content-hashed against a quoted span |
| `V3` | ≥2 **independent** sources agree (different kind, or different host) |
| `V4` | replicated primary (peer-reviewed replication / pre-registered RCT) |

**5. Confidence is capped at `min(tier, verification)`.**

```
per-source cap = min(TIER_CAP[tier], VERIFICATION_CAP[verification])
claim cap      = max(per-source caps)            # a claim rests on its best support
               → 0.95 if two independent sources resolved   (V3)
               → 0.60 if any source is unresolvable         (asserted support that isn't there)
               → 0.60 if nothing resolved                   (V0)
```

`TIER_CAP`: T1 `0.99` · T2 `0.95` · T3 `0.80` · T4 `0.60` · unknown `0.60` · Rejected `0.0`.
`VERIFICATION_CAP`: V0 `0.60` · V1 `0.80` · V2 `0.95` · V3 `0.95` · V4 `0.99`.

**This is what makes the CLAUDE.md calibration table enforceable rather than decorative.**
The `>95%` band authorises autonomous execution; under this rule it now requires T1–T2
provenance at V2+, or V3 across independent lines. A claim may not be stated above its cap.

**6. Independence is checked, not assumed.** Two sources of the same kind on the same host
are one line of evidence. This is the citation-cascade trap caught in the wild during the
same session: five "independent" ROI statistics that all traced to one undocumented claim
laundered through five marketing hosts.

**7. A `/claim` skill** ([`.claude/commands/claim.md`](../.claude/commands/claim.md)) makes
the compliant path the easy path. The prior instruction was "use `Bash` with a single-line
`echo` redirect", and that friction is a sufficient explanation for why the introspective
subset went dark.

**8. A `claim-provenance` soft doctor check**, offline-only over the last 14 days, reporting
two findings separately: unresolvable citations, and claims stated above their cap.
Over-confidence is judged **only when every source was checkable**, so an offline run never
cries wolf.

## Evidence basis

> Required v0.4+ per [LR-05](../constitution/local-rules.md#lr-05).

- **Primary, peer-reviewed, with public replication:** Dahl, Magesh, Suzgun & Ho, *Large
  Legal Fictions*, Journal of Legal Analysis
  ([arXiv:2401.01301](https://arxiv.org/abs/2401.01301) ·
  [RegLab](https://reglab.stanford.edu/publications/hlarge-legal-fictions-profiling-legal-hallucinations-in-large-language-models/) ·
  [repo](https://github.com/reglab/legal_hallucinations)) — >800k questions; 58–88%
  hallucination; models cannot predict their own. `[T1][V1]`
- **Primary:** *Cited but Not Verified: Parsing and Evaluating Source Attribution in LLM
  Deep Research Agents* ([arXiv:2605.06635](https://arxiv.org/html/2605.06635v1)). `[T1][V1]`
- **Primary:** *Citation Grounding* ([arXiv:2606.00898](https://arxiv.org/pdf/2606.00898)) and
  *CiteCheck* ([arXiv:2605.27700](https://arxiv.org/html/2605.27700v1)) — 11–57% deployed
  rates; retrieval-grounded verification with Exact/Minor/Major labels, the pattern this
  ADR's three-state model follows. `[T1][V1]`
- **Corroborating (independent method):** AttributionBench (~80% macro-F1 ceiling) and
  CiteME (4–18% accuracy) — establishing that a judge is *not* a sufficient checker, which
  is why this module is deterministic. `[T1][V1]`
- **Internal, V2:** the egress-block finding of 2026-08-13 (probe results in the evidence
  review §0.1) — the three-state model's motivating case.
- **Independence analysis:** four lines spanning general benchmarks, agent behaviour,
  automatic-checker limits, and a peer-reviewed legal-domain replication. Different
  instruments; they cannot easily be wrong the same way. See
  [`research/2026-08-13-agentic-efficacy-and-validation-evidence-review.md`](../research/2026-08-13-agentic-efficacy-and-validation-evidence-review.md) §3.4.
- **What would change this call:** evidence that models *can* reliably self-assess citation
  accuracy, which would make the deterministic resolver redundant. Four independent lines
  currently say the opposite.

## Cost model

Per [LR-06](../constitution/local-rules.md#lr-06). **Offline path: $0, no network, no
inference** — `existsSync` plus one `readFile` per quoted source. **Online path:** one HTTP
GET per remote source with a 15s timeout, opt-in via `--online`; no model calls ever. Doctor
stays offline by construction so it remains fast and deterministic.

## Consequences

**Locks in:**
- `claim_provenance_result` as an event type; `provenance-integrity` in the ADR-0059 verdict.
- The `unreachable` ≠ `unresolvable` distinction, permanently.
- Confidence capped by provenance — the calibration table becomes enforceable.
- The quoted-span content hash as the only route to `V2`.

**Locks out:**
- Self-asserted provenance earning a high-confidence band.
- Treating a 200 response as evidence that a claim appears in the page.
- Using an LLM judge as the citation checker.

**Migration:** existing claim events remain valid and are simply reported as unchecked. No
rewriting of history — and deliberately so: retro-stamping old claims with provenance they
never had would be exactly the fabrication this ADR prevents.

## Alternatives considered

- **Binary valid/invalid.** Rejected on contact with reality — the session's own proxy block
  would have marked 21 legitimate T1 sources invalid.
- **Have the Critic review citations.** Rejected — AttributionBench's ~80% ceiling and
  CiteME's 4–18% say a judge is not up to it, and it costs money to be worse than `existsSync`.
- **Require V2 for every claim.** Rejected — unachievable behind an egress proxy, and an
  unachievable rule gets disabled. The cap mechanism degrades gracefully instead.
- **Cap on the *weakest* source rather than the strongest.** Rejected — it would punish
  citing extra corroboration, discouraging exactly the behaviour we want. Unresolvable
  sources are handled separately, as a defect.
