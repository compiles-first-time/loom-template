> **Requirement source:** handoff 2026-07-15 "Pending work" #3 → [ADR-0055](../../../adr/0055-shared-lessons-learned-service.md) **Phase 0**; design in [`docs/proposals/lessons-learned-service.md`](../../../docs/proposals/lessons-learned-service.md).

> **Solution:** [`scripts/lib/lessons.mjs`](../../../scripts/lib/lessons.mjs) (schema + parser + `searchLessons` + soft-checks) with [`scripts/lessons.sh`](../../../scripts/lessons.sh) / [`.ps1`](../../../scripts/lessons.ps1) wrappers; schema conformance surfaced by [`scripts/lib/doctor.mjs`](../../../scripts/lib/doctor.mjs) `checkLessonSchema()`. > **Validated by:** [`scripts/lib/lessons.test.mjs`](../../../scripts/lib/lessons.test.mjs) (12 cases = the 8 Phase-0 acceptance *criteria* formalized from the proposal + smoke, malformed-tolerance, real-load conformance, and real-**value** correctness). Cases: [`BR_10.cases.mjs`](./BR_10.cases.mjs).
> **Live view:** `node scripts/lib/lessons.mjs search "<q>"` / `validate`; `loom doctor` → `lesson-schema (warn)`.

The ask (ADR-0055 Phase 0, zero-infra): **standardize the lesson frontmatter schema + ship `loom lessons search` over local files + soft-check validation** — no canonical store, no hosted index yet. This unblocks the Phase-1 store without requiring infrastructure now, and makes Loom's lessons a *compounding* asset (ADR-0054 memory axis) instead of per-repo dead weight.

## Known limitations (tracked, not hidden)

- **Local-only, keyword + metadata (Phase 0 by design):** no canonical `loom-lessons` store, no hosted index, no MCP tool yet — those are Phase 1–2 (ADR-0055), gated on `constitution-service` for the cross-project data-egress concerns. Dedup uses token-overlap (Jaccard), a zero-infra stand-in; embedding-based dedup arrives in Phase 1.
- **Soft-checks are warnings (Phase 0):** schema, secrets, confidence-sanity, dedup, and share-flag checks warn rather than block; the critic + PR review enforce hard gates in Phase 1+ (proposal).
- **Auto-derived tags for legacy lessons:** the 3 most-relevant lessons carry curated `domain`/`stack`/`platform`; the other 9 were migrated with tags inferred from filename + body (title from each H1, provenance sources from in-body `ADR-####` references). All 12 conform; tags can be refined by hand over time (LR-05 supersede).
