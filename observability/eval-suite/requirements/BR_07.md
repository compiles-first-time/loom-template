# BR_07 — Multi-LLM deliberation panel (disciplined)

> **Requirement source:** handoff 2026-07-15 "Pending work" #1 + deliberation-panel decision → [ADR-0056](../../../adr/0056-multi-llm-deliberation-panel.md).
> **Registry format:** [ADR-0046](../../../adr/0046-requirements-exceptions-testcase-registry.md) (extends [ADR-0022](../../../adr/0022-xlsx-docs-convention.md)).
> **Solution:** [`scripts/lib/deliberation.mjs`](../../../scripts/lib/deliberation.mjs) (pure cost-gated robust aggregation) + [`scripts/lib/deliberation-models.mjs`](../../../scripts/lib/deliberation-models.mjs) (live Ollama 2nd-model adapter). Weights from [BR_06](./BR_06.md) reputation projection.
> **Validated by:** [`scripts/lib/deliberation.test.mjs`](../../../scripts/lib/deliberation.test.mjs) (15 cases; deterministic, injected adapters). Live proof: [`examples/deliberation-live.mjs`](../../../examples/deliberation-live.mjs) (also emits a `loop_cost_summary`, LR-06). Cases: [`BR_07.cases.mjs`](./BR_07.cases.mjs).
> **Live view:** Observatory → **Requirements** panel.

The ask: **a disciplined multi-LLM decision, not naive N-model voting** — cheap by default (self-consistency), cost-gated (LR-06), reputation-weighted with ROBUST aggregation (capped weights / weighted median → one bad agent can't swing it), model-diverse with a **live** 2nd model (local Ollama), and confidence priced on *effective independence* not raw N. The two named business exceptions are the crux: a panel that confidently returns a shared-wrong answer (confabulation consensus), and a compromised/over-weighted agent swinging the vote.

## Live proof (actual — 2026-07-15, warm Ollama `llama3:8b-instruct-q4_K_M`)

`node examples/deliberation-live.mjs` — "What is the capital city of Australia?" (Sydney | Canberra | Melbourne), stakes=true → gate escalates → live 2nd-model vote cast:

```json
{ "answer": "Canberra", "confidence": 0.632, "method": "panel:reputation-weighted-vote",
  "effectiveIndependence": 2, "escalate": false, "flags": ["uniform_weights_no_reputation"], "cost": 2,
  "votes": [ {"agent":"claude#1","family":"claude","answer":"Canberra"}, …,
    {"agent":"ollama/llama3:8b-instruct-q4_K_M","family":"llama","answer":"Canberra",
     "reason":"Canberra is the capital city of Australia, located in the Australian Capital Territory (ACT)"} ] }
```

The **second model really ran** (a genuine non-Claude vote). Contrast: with Ollama unavailable the same call degrades to independence 1 → `confabulation_consensus_suspected`, confidence 0.393, escalate — exactly the error-correlation discipline working.

## Known limitations (tracked, not hidden)

- **Claude arm is model-in-the-loop (SE, honest):** the self-consistency samples are supplied by the orchestrating model (the Loom Claim convention), not a separate live Anthropic API call. The *second* model is genuinely live (Ollama). A live Claude-API arm would slot into the same adapter interface.
- **Independence is label-based:** effective independence uses declared `family`/`model`. Unlabeled votes are counted as independent (we can't prove unseen correlation) — so always label votes with their model family for the confabulation guard to bite.
- **Thresholds are provisional:** the cost-gate / confabulation thresholds are informed defaults; the ADR-0054 Phase-1a eval harness will tune them against measured lift.
- **Single debate round only:** elaborate multi-round debate is deliberately reserved (the evidence says voting≈debate).
- **Robustness scope = one corrupted SOURCE (SE, critic re-review 2026-07-15):** the swing guard removes the single strictly-heaviest *family*, so one compromised source can't swing the plurality even by splitting into multiple votes (BR-07_BE-02c). Two *independent* colluding families (≥2 corrupted sources) can still win a split plurality — out of scope for v1, tracked for the ADR-0054 eval harness. Numeric answers are 50%-breakdown robust (weighted median) regardless.
- **Reputation-decisiveness is conservatively escalated (SE):** the guard can't tell a legitimately-decisive high-reputation vote from a compromised one — when a single source is decisive it escalates rather than autonomously resolving. Safe (never silently returns a swung answer), but it means reputation weighting alone won't auto-resolve a contested call; that's the escalation path's job.
