# BR_12 — Governed decision: the deliberation panel as a real decision path (ADR-0056)

> **Requirement source:** whole-template map (2026-07-15) finding — the deliberation panel (ADR-0056) was a standalone library with no entry point, no event emission, and no Observatory presence ("the deliberation panel as a user-facing feature does not exist yet").
> **Registry format:** [ADR-0046](../../../adr/0046-requirements-exceptions-testcase-registry.md).
> **Solution:** [`scripts/lib/governed-decision.mjs`](../../../scripts/lib/governed-decision.mjs) (`governedDecision` + `loadReputationWeights`) over [`deliberation.mjs`](../../../scripts/lib/deliberation.mjs); emits a `deliberation` event handled by [`observatory/lib/aggregator.mjs`](../../../observatory/lib/aggregator.mjs) and rendered by the new **Deliberation** panel in [`observatory/public/js/app.mjs`](../../../observatory/public/js/app.mjs). Live proof: [`examples/governed-decision-live.mjs`](../../../examples/governed-decision-live.mjs).
> **Validated by:** [`scripts/lib/governed-decision.test.mjs`](../../../scripts/lib/governed-decision.test.mjs) (5 cases; the emit case spawns the entrypoint in a temp Loom root and reads back the `deliberation` event). Cases: [`BR_12.cases.mjs`](./BR_12.cases.mjs).
> **Live view:** Observatory → **Deliberation** panel + activity feed (`deliberation`).

The ask: **make the panel a real, observable decision — not a demo library.** `governedDecision` aggregates AGENT reviewer verdicts (critic / constitution-service / human-replica) with the disciplined panel, weights each reviewer by its **live reputation score** (BR_06 projection — closing the reputation→panel loop), adds a live non-Claude tiebreaker (Ollama), and emits a `deliberation` event the Observatory renders. Reputation weighting here is **aggregation of opinions already offered**, not dispatch steering (ADR-0053 Step 3, still gated on constitution-service) — Rule-2-safe.

## Live proof (2026-07-15)

`node examples/governed-decision-live.mjs` — reviewers split (critic + constitution-service → reject; human-replica + live llama3 → approve). Result: `approve @0.324`, effectiveIndependence 2, **escalate: true** (flag `low_confidence`) — a contested, low-confidence decision is escalated to a human, not acted on (the confidence-floor discipline this live run surfaced).

## Known limitations (tracked, not hidden)

- **Reviewer votes are supplied by the caller (model-in-the-loop):** the base agents' verdicts are provided by the orchestrating session (the Loom Claim convention), as with the panel's Claude arm; the 2nd model (Ollama) is genuinely live. A future wiring has the critic/constitution/human-replica subagents call `governedDecision` directly.
- **Not yet wired into the Update Bus (L7):** the natural next integration is aggregating the Update Bus's Critic + Human-Replica verdicts through this path; today `governedDecision` is a callable primitive + a live example, not yet the Update Bus's default aggregator.
- **Reputation weighting ≠ dispatch:** weighting offered votes is projection/aggregation; using reputation to choose WHICH agent runs is ADR-0053 Step 3, gated on constitution-service.
