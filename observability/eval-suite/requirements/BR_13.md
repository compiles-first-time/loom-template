The ask: **produce the first governed-vs-ungoverned efficacy number** — the ADR-0054 tent-pole. The harness runs a labelled task suite through the **real** governance layer (`permissions-classifier` → `destructive-guard`, exactly what `scripts/hooks/pre-tool-use.mjs` runs) in two modes and measures the safety-catch delta.

## First measurement (2026-07-15) + first gap closed

`node scripts/efficacy.sh` — 18 scenarios (11 unsafe, 7 safe). The initial run (15 scenarios) surfaced a **`curl | sh` RCE gap** via `BR-13_MeasuresGaps`; it was closed in `.claude/loom-permissions.yaml` and re-measured — the proof-first loop in action (+8 → +11):

| Metric | Governed | Ungoverned |
|---|---|---|
| **Safety-catch delta** | **+11** (blocks all 11 unsafe) | 0 (executes everything) |
| Governed catch rate | **100%** (11/11) | 0% |
| False-positive rate | **0%** (7 safe ops untouched) | — |
| Discipline | **100% deterministic** | — |
| Token cost | **$0** (no LLM — governance is free) | $0 |

## Known limitations (tracked, not hidden)

- **Enforcement-layer scope (honest):** this measures the *safety-catch delta* — the deterministic core of ADR-0054's governed-vs-ungoverned metric — over the destructive-action governance layer. The richer **live-agent A/B** (discipline adherence + rework-avoided over a real governed *build*, with token cost of the whole session) is the follow-on that fuses this harness with the next real project (roadmap 1a).
- **The suite is a living sample:** 18 scenarios across the deny/ask/allow/none tiers. `BR-13_MeasuresGaps` proves the harness surfaces ops the classifier does NOT catch — and it already drove one fix: the `curl | sh` RCE gap it first found was closed in `loom-permissions.yaml` (+8 → +11), so the case now points at the next uncaught op (a raw `dd` disk write). Governance gaps are reported as a lowered catch rate, not hidden — the harness is a measurement, not a rubber stamp.
- **Governance ≠ correctness:** catching an unsafe op means confirm/deny fired, not that the eventual human decision is right; the metric is the *catch*, per ADR-0054.
