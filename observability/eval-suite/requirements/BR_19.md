## Known limits

- **Owner-role vocabularies are lists, not ontologies.** `RUNTIME_ROLES`/`HUMAN_ROLES` cover the roles the existing registers use; a new register using `"ops team"` would read as a gap until the vocabulary grows. Wrong-direction failure is safe: a false gap asks the EAC a question a human reviews at HR registration; a false match would silently drop a needed specialist.
- **Sequencing is register order.** Without the deferred `Next Step` column (ADR-0061 §Deferred) the graph has nodes and packets but not explicit edges; restoring that column upgrades this from a dispatch list to a true DAG.
- **The end-to-end loop (gap → EAC synthesis → HR registration → dispatch) has not yet run on a real project.** This register proves the trigger mechanism; the proof project proves the loop. That is the named next milestone (ADR-0054 Phase-1a fused with the pipeline).
